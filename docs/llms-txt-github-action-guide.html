Add an llms.txt, AI Crawler & Schema.org JSON-LD CI Gate in GitHub Actions

Prevent accidental CDN rules, Next.js/Astro layout refactors, or broken JSON-LD edits from silently tanking your visibility in ChatGPT Search (OAI-SearchBot), Perplexity (PerplexityBot), and Claude (ClaudeBot).

Step 1: Add zColdWater/citeready-cli@v1 to .github/workflows/geo-audit.yml

Runs in under 4 seconds with zero npm install overhead, writes a formatted Markdown scorecard straight to your GitHub Actions Job Summary ($GITHUB_STEP_SUMMARY), and fails the workflow if your score drops below your threshold: 

name: AI Search (GEO) & Technical SEO Gate

on:
  push:
    branches: [main]
  schedule:
    - cron: "0 9 * * 1" # Weekly production drift check

jobs:
  citeready:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/setup-node@v4
        with:
          node-version: "20"

      - name: Audit Production AI Citation Signals
        id: geo
        uses: zColdWater/citeready-cli@v1
        with:
          url: "https://yoursite.com"
          min-score: "80"
          require-llms-txt: "true"
          require-jsonld: "true"

      - name: Read Action Outputs
        run: echo "GEO Score ${{ steps.geo.outputs.score }}/100 (Grade ${{ steps.geo.outputs.grade }})"

Step 2: Production robots.txt Policy (Allow Search Citation Bots)

Want ChatGPT Search and Perplexity to cite your pricing and docs while keeping unattributed bulk training crawlers out? Separate search user-agents from training user-agents explicitly: 

# Allow live AI Search & Citation Engines
User-agent: OAI-SearchBot
Allow: /

User-agent: PerplexityBot
Allow: /

User-agent: ClaudeBot
Allow: /

# Standard web search
User-agent: *
Allow: /

Sitemap: https://yoursite.com/sitemap.xml
